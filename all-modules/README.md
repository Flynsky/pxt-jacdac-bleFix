# jacdac-all-modules

Adds every Jacdac module client (button, rotary encoder, LED, servo, sensors, ...) of the
Bluetooth-compatible fork in one go, instead of adding each module extension separately.

In MakeCode: Extensions → paste `https://github.com/Flynsky/pxt-jacdac-bleFix/all-modules`
(together with `https://github.com/Flynsky/pxt-jacdac-bleFix`).

All entries point to this fork. Do not mix them with module extensions from `jacdac/pxt-jacdac`,
otherwise MakeCode sees two different `jacdac` packages and marks Jacdac as invalid.
